# Оценка рыночной стоимости коммерческой недвижимости (ПСН) в Санкт-Петербурге с помощью ML

Проект по прикладному анализу данных и машинному обучению для экспресс-оценки рыночной стоимости помещений свободного назначения (street retail) в Санкт-Петербурге на основе данных витрины ЦИАН.

---

## 📌 Бизнес-задача

Определить справедливую рыночную цену и коридор предложения для коммерческого помещения (ПСН) площадью 94 м² (1 этаж, отдельный вход с улицы, ст. м. «Рыбацкое») перед выходом на открытый рынок и совершением сделки.

---

## 🛠 Стек технологий

* **Язык:** Python 3.10+
* **Библиотеки анализа данных:** `pandas`, `numpy`
* **Машинное обучение:** `scikit-learn` (`RandomForestRegressor`, `KFold`, `mean_absolute_percentage_error`)
* **Регулярные выражения:** `re` (парсинг локаций, этажности и транспортной доступности)

---

## 📊 Данные и предобработка

Датасет сформирован на основе выгрузки актуальных объявлений ЦИАН по помещениям свободного назначения площадью 50–200 м² в жилых домах Санкт-Петербурга (200 объектов).

### Ключевые этапы подготовки признаков:
1. **Таргет (`price_per_m2`):** удельная цена за квадратный метр (`Цена / Площадь`). Это снижает дисперсию и устраняет зависимость ошибки от масштаба помещения.
2. **Локация (`metro_clean`, `metro_time`):** с помощью регулярных выражений извлечено чистое название станции метро, а также время в пути в минутах. Пропуски времени заполнены медианным значением.
3. **Группировка этажности (`floor_group`):** нелинейный признак агрегирован в бизнес-категории (`1 этаж`, `подвал/цоколь`, `2+ этаж`).
4. **Тип входа (`entrance_clean`):** стандартизированы категории входных групп (`с улицы`, `со двора`, `не указан`).
5. **Кодирование:** категориальные признаки преобразованы через One-Hot Encoding (`pd.get_dummies`).

---

## 🤖 Моделирование и валидация

* **Модель:** ансамбль деревьев решений `RandomForestRegressor(n_estimators=150, max_depth=8)`.
* **Схема валидации:** 5-Fold кросс-валидация со стратификацией по случайному сиду.
* **Основная метрика:** **MAPE (Mean Absolute Percentage Error)**.

### Результат валидации:
$$\text{MAPE} = 17.9\%$$

Для сегмента коммерческой недвижимости малой выборки ошибка в пределах 15–20% является стабильным и адекватным показателем качества модели.
